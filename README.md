PharmaBase 💊
A blockchain-based medicine tracking system to detect counterfeit drugs.

Features
Add medicine
Verify medicine authenticity
Transfer ownership
QR scanning
Location tracking
-History of the MEdicine
Tech Stack
Frontend: React.js
Backend: Node.js / Express
API: Axios
HyperLedger Fabric for BlockChain Implementation
Docker to run the BlockChain Network
How to Run
Frontend
cd frontend npm install npm start

Backend
cd backend npm install node app.js

you mush on the Docker Engine and Docker Compose to run all the Containers Change the Path according to the Containers Network where the BLockChian is Running
